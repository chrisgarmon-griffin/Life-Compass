# Life Compass

A standalone personal life guide inspired by Dan Koe's HUMAN 3.0. Original reflection exercises complement a short, attributed framework summary.

## Use

Open `index.html` in a modern browser, or deploy the repository on Vercel as a static project. There are no dependencies or build steps.

Includes daily check-ins, a life map, practice library, seven-day experiments, journal search, weekly reviews, and JSON backup import/export.

## Data and moving between hosts

Personal entries stay in browser localStorage. They are not committed, uploaded, or synced. A different domain or browser has separate storage. Export a backup from the original site under **Framework & your data**, then import it on the new site. Keep backups somewhere private. Anyone with access to your browser profile may be able to read its entries.

## Design

Self-contained inline SVG icons with consistent 24 × 24 viewboxes, centered fixed-size containers, shared control sizing, responsive cards, visible keyboard focus, and reduced-motion support. No external fonts, image services, or trackers.
